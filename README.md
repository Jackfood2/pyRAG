# Offline RAG workstation

1. Run `Start-Offline-RAG.bat`. It starts the package-local embedding service, BGE cross-encoder reranker, and web app. LM Studio is not used for retrieval.
2. Rebuild the index.
3. Query locally. No document data is sent to the internet.

The `models` folder contains Nomic Embed v1.5 for semantic search and BGE Reranker v2-m3 for local cross-encoder reranking. The `runtime` folder contains the local CPU inference executable and `python` contains the Windows x64 Python runtime. The app includes its own offline `pypdf` reader for normal text-based PDFs, as well as built-in TXT, DOCX, XLSX/XLSM support. Image-only/scanned PDFs require OCR before ingestion because no OCR engine is included. Excel is indexed as one independently searchable record per sheet row, with original column names and row number preserved in citations.

To move it, zip the entire `Ingest` folder (including `OfflineRAG`) and extract it anywhere on a 64-bit Windows PC. The source folder automatically uses the extracted `Ingest` folder, so no paths need editing. Python, the retrieval runtime, embedding model, and reranker are bundled. LM Studio is optional and is used only when you select an answer model; Evidence only works with no LM Studio installed.

Retrieval uses boundary-aware passage chunks, semantic vector search, and BM25 exact-term search fused with reciprocal-rank fusion. The bundled BGE cross-encoder then reranks the candidate passages when available. This combination preserves exact names, identifiers, and numbers while also finding semantically related evidence. Bundled `nomic-embed-text-v1.5` is the embedding model and `bge-reranker-v2-m3` is the cross-encoder reranker; these are strong, compact local models and require no additional downloads. BM25 postings and normalized vectors are built during ingestion, keeping question-time retrieval fast even for larger local collections. If the reranker service is unavailable, hybrid evidence search continues instead of failing. The launcher assigns all detected logical CPU cores to the bundled local model servers, and the app reports the detected CPU/RAM profile. LM Studio is used only for the final cited answer through its OpenAI-compatible `/v1` API; set either `http://127.0.0.1:1234` or `http://127.0.0.1:1234/v1`, select a model in the interface, and load it if needed. Models are discovered once at page load and only refresh when requested. Rebuild after updating to this version because the index format has changed.
